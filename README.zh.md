# cursorclaw

[codexclaw](https://github.com/lidge-jun/codexclaw) 的 **Cursor 运行时分支**。把同样的开发纪律（dev skill 家族、PABCD、子代理角色）打成 Cursor 插件，而不是 Codex 插件。

当前为 **0.1.0 scaffold**。移植对照见 [PORTING.md](PORTING.md)，上游钉扎见 [UPSTREAM.lock](UPSTREAM.lock)。

## 安装

1. Clone 本仓库。
2. 在 Cursor **Customize → Plugins** 中添加本仓库（或 `plugins/cursorclaw`）。
3. 重启 agent 会话并确认 `sessionStart` 横幅。
